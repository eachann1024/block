1. 虚拟幽灵引导行（零脏数据） layout.rs / view.rs

当文档首块是结构块时，视图层在首块上方渲染一行 34px 虚拟占位行。仅在用户点击并实际输入字符时才实例化为 Doc 中的真实 Paragraph，未输入离开绝不修改 Markdown 源码。

2. 首字符 Enter 整体下推代码块 enter_rules()

解除 enter_rules() 对首块 offset == 0 的一刀切拦截：当光标位于代码块第 0 个字符 |{ 时按 Enter，与普通标题/列表一致在上方插入新段落并将代码块整体下移（块内首行换行用 ⇧Enter）。

3. ↑ 键平滑进出虚拟行 vertical()

光标在代码块第一行或表格第一行按 ↑，直接进入上方的虚拟幽灵行；在虚拟幽灵行按 ↓ 或 Esc 则无缝回到原结构块首行，保持纯键盘流顺畅往返。
