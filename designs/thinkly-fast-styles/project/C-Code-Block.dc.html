代码块居右控件 · 页面滚动即收起的通用下拉
1. 普通代码块：复制 + 语言胶囊居右。语言菜单打开后滚动这一栏，菜单立即收起。

在 Rust 里读取配置文件，然后按需合并默认值：

fn load_config(path: &Path) -> Result<Config> { let raw = fs::read_to_string(path)?; // 缺失字段回落到默认值 let cfg: Config = toml::from_str(&raw)?; Ok(cfg.merge(Config::default())) }

闲置时代码块只有底色；悬停或光标进入后才出现复制按钮和语言胶囊。

3. 通用下拉组件 Dropdown：全局所有下拉（代码块语言、块菜单、表格菜单、图片菜单、设置选择框）共用
分组标题
容器
白底、圆角 12、内边距 4、无描边；三层阴影（1px 轮廓 + 8/24 + 2/6）；宽 160–320
高度
最高 304（且不超过窗口高 − 16），超出在菜单内部滚动，滚动不外溢
行
高 28、左右 10、间距 8、圆角 8、14px；悬停与选中底色 rgba(11,11,11,.05)
图标列
16px 前置图标，颜色 #52514e；无图标的行保留 16px 空位，文字始终对齐
选中
行尾 16px 对勾，左侧留 12
分隔 / 分组
1px 分隔线上下 4；分组标题 13px 中粗灰色
危险行
文字 #8e2626；悬停整行红底 #d03b3b、白字
定位
右边缘对齐触发按钮，顶部在按钮下方 4px；下方放不下翻到上方，始终离窗口边 8px
收起
页面或编辑区任意滚动、点击外部、Esc、选中一项、窗口失焦时立即收起，触发按钮恢复未展开态
键盘
↑ ↓ 移动高亮，Enter 选中，打开时高亮当前选中项
