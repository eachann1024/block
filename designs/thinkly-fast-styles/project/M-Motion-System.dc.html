Rust + GPUI 0.2.2 动画库调研选型与直接调用规范（零自研引擎）

主力状态过渡库：gpui_transitions = "0.1.5"（MIT） 精确匹配 gpui = "=0.2.2"
解决 GPUI 原生 with_animation 无法中途平滑反向、无退场状态保持的痛点；提供与 use_state 同构的 window.use_keyed_transition，内置 f32、Pixels、Hsla、Point、Size 与 BoolLerp 线性插值，未完成时自动请求下一帧。
use gpui_transitions::{BoolLerp, WindowUseTransition};
use gpui_component::animation::cubic_bezier;

let reveal = window.use_keyed_transition(
    ("handle-reveal", block_id),
    cx,
    Duration::from_millis(120),
    |_, _| BoolLerp::new(false),
).with_easing(cubic_bezier(0.22, 1.0, 0.36, 1.0));

let t = reveal.evaluate(window, cx).value();
row.opacity(t).ml(px(-3.0 * (1.0 - t)))
内置挂载进场库：gpui::AnimationExt + gpui_component::animation 已在 Cargo.toml 零新增依赖
适合右键菜单、斜杠块菜单、图片胶囊浮条、链接浮层等挂载即播放的一次性进场（One-shot Entrance）；直接组合 gpui::Animation::new 与 gpui_component::animation::cubic_bezier(0.16, 1.0, 0.3, 1.0)。
use gpui::{Animation, AnimationExt, px};
use gpui_component::animation::cubic_bezier;

menu_card.with_animation(
    ("popup-enter", menu_epoch),
    Animation::new(Duration::from_millis(160))
        .with_easing(cubic_bezier(0.16, 1.0, 0.3, 1.0)),
    |card, delta| {
        card.opacity(delta).mt(px(-4.0 * (1.0 - delta)))
    },
)
