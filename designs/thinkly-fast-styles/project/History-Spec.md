# 页面历史（Page History）交互与存储边界说明

> 用户已选定 **方案 A（右侧版本栏）**，方案 B / C 归档至「页面历史备选」页。本文为设计规格与边界定义，供后续客户端实现对齐；本轮仅输出设计稿与规格，不修改 `src/` 代码。

## 1. 全量自动保存与后台历史归档

- **全量自动保存**：产品无手动保存功能，界面不设保存按钮、保存来源标签（如「手动保存」「自动快照」）或打开历史前的保存确认。
- **后台快照归档**：历史快照是后台按时间点生成的内容归档，与日常自动保存不是同一个用户操作。内部聚合策略（建议停笔 `30s` 或持续输入满 `5min` 归档一次、无变化按 SHA-256 指纹去重、单页保留上限）属于后台待确认规则，不在 UI 上展示技术说明或承诺永久保留。
- **进入历史与恢复前保留**：进入「页面历史」时直接读取已自动保存的当前内容（若有正在进行的写入由内部协调等待，无用户侧「先保存」步骤）。执行恢复前，自动将当前内容保留在历史记录中。
- **标识与撤销独立**：历史绑定页面稳定 ID（重命名或移动不断裂），与编辑器内存级 `⌘Z / ⇧⌘Z` 栈独立。

## 2. 界面与文案极简规则

- **常态零冗余解释**：常态界面只显示版本时间、当前版本的「当前」轻文字标识、「原文 / 对比」切换与「恢复此版本」按钮；不显示版本摘要小字、来源角标、对比方向常驻说明或底部键盘提示。仅在异常或禁用时解释原因。
- **入口与版心**：从顶栏 `⋯ → 页面历史…` 进入，右侧展开 `320px` 版本栏并收起左侧文件栏，保持正文标准阅读版心。只读预览支持选择与 `⌘C` 复制。
- **原文与对比**：默认显示所选版本只读「原文」；切换「对比」时按「所选旧版本 → 当前版本」呈现块级差异（删除块带删除线与「已删除」，新增块带浅蓝底、`1px` 强调内轮廓与「+ 新增」）。
- **整页恢复与撤销**：
  - 按钮固定为「恢复此版本」；选中当前版本或与当前内容相同时禁用（原因仅通过 `title` / `aria-label` 说明）。
  - 确认弹窗标题为「恢复到「时间」？」，正文仅一句「当前内容会保留在历史中。」，操作为「取消 / 恢复」。
  - 恢复后将所选版本作为新版本写入并退出历史，顶部提示「已恢复到「时间」」并提供「撤销恢复」；撤销后提示「已撤销恢复」。

## 3. 数据安全与异常保护

- **外部资源边界**：仅版本化 Markdown 文本，不回滚 `assets/` 等图片附件；缺失图片按标准占位框渲染。
- **冲突、只读与失败处理**：
  - 打开历史后若底层文件发生外部更新，提示「页面已更新，请重新对比。」并提供唯一「重新对比」操作。
  - 文件只读时提示「此页面只读，无法恢复。」并禁用恢复。
  - 列表加载失败提示「历史记录加载失败」并提供「重试」；恢复写入采用原子替换，失败时保留原内容完好，提示「恢复失败，当前内容未更改。」并提供「重试」。
- **竞态与焦点**：快速切换版本时丢弃过期异步读取；`↑ / ↓` 在列表内切换版本，`Escape` 逐层关闭弹窗或退出历史并归还编辑器焦点与滚动位置。
