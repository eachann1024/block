1. 顶缘 24px 感应槽与点击上插 chrome.rs / interaction.rs

当文档第 0 个块为非普通段落（代码块、表格、分割线、图片、Callout）时，首块上方预留 24px 顶缘感应区。鼠标移入时显现左侧 + 按钮与 1px 虚线引导槽，点击任意位置直接在索引 0 处插入空段落。

2. 首字符 ↑ 与 Backspace 破壁 block_shortcuts.rs

当光标停在首块最开头（block 0, offset 0，如截图中的 |{）时，按 ↑（Up）或 Backspace 不再静默吞掉按键，而是在代码块上方自动插入一个空段落并将光标移入，无需鼠标即可跳出首块。

3. 全类结构块统一覆盖 table / divider / image

同一套顶缘感应与键盘破壁逻辑同时作用于首块为表格（首格 offset 0 按 ↑）、分割线、图片或引用块的情形，彻底消除文档顶端结构块「上方死区」。
