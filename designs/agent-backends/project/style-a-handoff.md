# 样式 A 实施说明

以 `StyleA.dc.html` 和既有推荐方案 `Main.dc.html` 为准；画板所有笔记、状态及操作均为模拟数据。演示状态选择器只用于原型验收，不进入产品。

## 布局与视觉

- 画板 1440 × 900；顶栏 40px，左侧栏固定 260px，聊天栏 380px，编辑区占剩余宽度。编辑正文居中，标准净宽 672–720px；窗口不足时保持编辑区可用宽度并按现有窗口约束处理，不提供全宽切换。
- 顶栏 `shell #f1f1f1`，侧栏 `sidebar #fafafa`，正文和聊天 `paper #ffffff`；分隔线 `#e6e6e6`，卡片线 `#e4e6ea`，控件边线 `#dcdcdc`。主文字 `#20242c`，编辑文字 `#1f1e1d`，次级 `#526071`。
- 使用项目 `DESIGN.md` 的 Ocean Paper 语义 token 和深色映射。界面 14px/20px，标题 16px/20px，编辑正文 16px/1.8；控件高 32px、圆角 8px，卡片圆角 12px，聊天水平内边距 16px，消息及卡片间距 16px。图标沿用现有 1.5px 双线语义图标。
- 默认按钮白底细边框；选中或主操作为 `#e5edfc` 配 1px `#547dd0`；hover `#eef3fc`；键盘 focus 使用清楚的 accent 轮廓；disabled 保持可辨识但降低透明度且不可触发。输入聚焦边框同 accent。
- 菜单和卡片进出场使用项目 motion，150–200ms、轻量淡入和位移；reduced-motion 关闭位移及过渡。无渐变或装饰性阴影。

## 交互及复用

- 后端选择在聊天栏头部，当前会话保持原绑定；切换后端需明确新建会话，取消保持原会话。新会话按钮沿用当前后端。后端未安装、认证未知、不支持、运行中、错误和审批均有对应状态，认证未知不能表述为已登录。
- 输入框左下为模型选择器，目录动态来自当前后端的 CLI/provider 实际可选模型及当前选择；不可用时显示本地化的默认/不可用状态，不把后端名当作模型。Claude 目录来自用户当前 CLI provider（可能是 Magpie），不推断订阅权限。dsh 的 SDK 候选为 `deepseek-flash`、`deepseek-v4-pro`，前者是应用回退值，不称为用户原生默认。画板的“模型 A/B”仅为示例。右侧保留发送/停止，输入 `@` 或点击引用按钮打开笔记选择。
- 引用菜单第一项固定当前笔记，其他笔记按稳定身份去重，不重复列出当前笔记；搜索、键盘上下选择、Enter 确认、Escape 关闭。选中后插入引用，引用实时内容；保留既有选区引用能力。菜单锚定输入区上沿，上方留 4px，左右与输入区对齐，最大高 200px、内部滚动，窗口空间不足时按可用空间调整，最后一项可滚动完整露出，禁止被输入区或窗口裁切。选中行 36px，`selected #e5edfc` 加 1px `accent #547dd0`，hover `#eef3fc`，圆角 8px。
- 切换后端创建新会话时清除旧消息、计划、审批和运行状态，保留编辑器正文及未发送草稿和引用；旧会话历史仍归原后端。运行中发送按钮切换为停止。审批必须允许或拒绝；修改先展示原文和建议，接受后可撤销，拒绝不得写入。
- 所有标签、空态与错误跟随现有应用 locale；服务名、模型名保留原名。会话区只显示简洁必要状态，不展示大段 CLI 版本或外部 MCP 技术说明。
- 优先复用 `src/ui/ai_controls.rs` 的输入和操作控件、`src/ui/dropdown.rs` 的菜单、`src/ui/icon_button.rs` 的图标按钮、`src/ui/popover.rs` 的浮层、`src/ui/motion.rs` 的动效及 `src/ui/radius.rs` 的圆角。缺少的通用状态卡或 diff 控件应抽到 `src/ui/`，业务侧只组合。
- 样式稿未验证实际账户、后端连接、实时上下文或写入行为；实施时需在真实窗口逐项验证。
