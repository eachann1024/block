现有线上官网（public/fast）的问题

  • 首屏像技术说明书：「本地 Markdown 块编辑器，Rust 编写，直接读写你硬盘上的 .md 文件」把架构、语言、读写方式塞成一句 32 字长句，缺少记忆点。
  • 副标题卖点堆砌过载：一句话同时塞进开源、无账号、不采集、拖拽、⌥N 便签、历史快照、⌘J AI 七件事，访客抓不住第一重点。
  • 丢掉了最大的「快」体感：明明是原生架构、十万段不卡，线上页只写了「Rust 编写」，没有把「大文档秒开不掉帧」转化成用户感知的利益。

动效版初稿（文字之隅）的问题

  • 首屏偏文青虚词：「文字之隅，落笔即成」放在书法或日记软件上也能用，第一眼看不出本地纯 .md、原生速度与块编辑这三个真本事。
  • 漏掉线上已有的杀手级功能：缺少了线上版很出彩的「⌥N 全局三槽速记小窗」「免 Git 本地自动版本对比」以及「直连本机 Claude Code / Codex Agent」。
  • 性能描述空泛：连写三个「毫秒级」不如真实实测数据（24.5 ms 打开 / 2.4 ms 上屏 / 117 MB 内存）有说服力。

版本一 · 利落直给

主抓「原生级快 + 纯 .md 归自己 + 顺手块操作」，平实有力，兼顾普通写作者与重度用户，最适合直接作为正式官网主文案。

版本二 · 器物温度

完全去掉技术词与跑分感，从「打开就写、挪动纸条般改稿、旧稿不丢」的日常写字体验切入，安静温和。

版本三 · 极客硬核

面向开发者与 Obsidian / VS Code 重度用户，突出压测硬指标、全键盘流、零锁定文件与直连本机 CLI Agent。
