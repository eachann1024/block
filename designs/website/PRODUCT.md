## Product

Block 是 macOS 原生的 Markdown 块编辑器。官网（`/fast/`）面向中文桌面写作者，定位为**性能 + 块编辑器为主，AI 和生成图片为辅**。主角是两件事：**性能**（十万块大文档即开即写，打开、输入、拖动都在毫秒内完成）与 **块编辑器**（每一段都是一个块，支持拖动重排、折叠章节、块类型随时转换、中文输入法全角标点直接触发，以及表格、代码、流程图和公式块渲染）；辅助介绍两项：**AI**（选中改写并审阅后才写入、侧边对话、改动可撤回）与**生成图片**（整篇或选中内容生成长图，可换纸张和配色）。引导用户在 Apple 芯片的 Mac 上下载使用。

## Users & Context

目标用户是日常使用 Markdown 写笔记、整理资料的 Mac 用户。他们关心大文档会不会卡顿、日常排版和中文输入顺不顺手、文件是不是直接保存在本地的 Markdown。页面去掉一切底层的技术名词和堆砌的功能罗列，让访客在几秒内看清真实界面、核心性能数据和块编辑的顺手交互。

## Brand Personality

克制、安静、利落。不靠技术黑话、跑分对比或复杂动效炫技，用充足的留白、平实的中文和真实的编辑器界面说话。

## Aesthetic Direction

- **色调基调**：温暖克制的纸面配色——暖白背景（`#FAF9F5` / `#F7F6F2`）、墨黑正文（`#141413`）、暖灰次级文字（`#5E5D59`）。陶土橙强调色（`#D97757` / `#C4613F`）仅用于主下载按钮和三个核心性能数字，其余界面元素全部使用墨黑与暖灰。
- **页面结构**：顶部导航（Block ｜ 性能 ｜ 块编辑器 ｜ AI ｜ 生成图片 ｜ 下载） → 首屏（直接以「文字之隅，落笔即成」为主体标题、主下载按钮、16:10 `#editor-stage` 真实编辑器窗口） → 性能区（三个核心指标并配与 VS Code、Obsidian、Notion 的直观横向对比） → 块编辑器区（拖动重排、折叠章节、随时转换、中文直接触发四项真实界面示意） → AI 区（`#ai`，三条说明加一张还原真实 AI 卡片的示意，篇幅和视觉权重不超过块编辑器区） → 生成图片区（`#image`，笔记与长图预览加纸张配色选项，同样轻于块编辑器区） → 下载区 → 单行页脚。
- **动态语言**：每页仅保留一个低对比点阵动画（点阵不透明度不超过正文墨色的 10% 量级），仅用于首屏背景或性能数字区域，播放一次或极缓慢循环，不抢夺编辑器窗口的视觉焦点，支持 `prefers-reduced-motion` 静止降级。
- **反例规避**：不堆叠花哨卡片、不做 Bento 宫格、不画外露网格线或标尺刻度、不加 eyebrow 或装饰角标、不展示底层技术栈名词。

## Principles

1. **性能与块编辑器为主，AI 和生成图片为辅**：首屏直接以「文字之隅，落笔即成」为主体；AI 与生成图片各占一个轻量版块，示意只用真实存在的选项名（润色、精简、翻译、应用修改、放弃；黑白素纸、手账便签、野性孔版），橙色不用于这两个版块。
2. **真实界面示意**：首屏 `#editor-stage`（预留 16:10 `<canvas>` 挂载点，不显示任何技术标注）与块编辑器区的四项小示意均还原 Block 真实界面。
3. **视觉高度克制**：版块之间留足空白，每屏只有一个视觉重点，正文不小于 14px。
4. **本地 Markdown 文件**：清晰说明适用于 Apple 芯片的 Mac，文件就是本地 Markdown。
