# 笔记 Markdown 指引

- 创建或修改笔记时使用编辑器支持的稳定 Markdown：标题、段落、列表、任务列表、引用、围栏代码块、链接、图片和简单表格。代码围栏独立成行，避免列表内嵌代码块、复杂 HTML 和其他编辑器不支持的结构。
- Markdown 标记直接使用原字符，不将 `#`、`*`、`>`、`|` 等标记转换为 HTML 实体。
- 密码、密钥、令牌、链接及其他凭据值必须逐字保留，不翻译、脱敏、转义、格式化或猜测；用户明确要求更改时除外。
- 不擅自修改或重写已有的不支持结构；保留其原文。只改用户要求的内容。
- `executeBatchPlan` 返回 `unsupported_markdown` 等结构预检错误时，参考错误定位修正计划，最多重试一次；不输出正文或凭据。
