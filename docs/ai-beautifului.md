# AI 面板：Beautiful UI

视觉依据：[Beautiful UI](https://www.beautifului.dev/)，[上游源码](https://github.com/slev12397/beautiful-ui) `44a274e598395ab61e7c96c26fda2758780253b7`。许可见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## 范围

- 01–02：像素网格加载、真实耗时、可折叠执行过程；运行、完成、失败、停止有独立状态。
- 03、05：流式回答、工具记录、真实来源和回复操作。
- 04：用户选择后再确认的审批卡；跳过不能授予权限。
- 07–08：历史会话切换、草稿、@ 引用、技能命令、模型选择与听写入口。按用户最新要求，移除整排会话标签及输入栏的引用快捷按钮。
- 09–11：将笔记变更方案、已检索上下文和编辑器差异映射到对应组件。

## 接入约定

上游是 React/Tailwind 演示；Block 使用原生 GPUI 组件。使用真实会话、工具和笔记数据，不复制示例回答、假计时、置信分数或循环演示。

聊天中的笔记修改只保留摘要、状态和编辑器入口。修改后全文、表格差异、接受与拒绝在编辑器内审阅；普通问答中的代码仍可显示。此约定优先于上游聊天内的 Diff 演示。

AI 专用色值、尺寸与动画在 `src/ui/` 统一维护，不改变编辑器和设置界面的全局视觉系统。深浅主题都应保持可读。

## 验证

交互验证使用项目后台 smoke worker 的隔离笔记与 GPUI 事件。可选 `smoke-capture` 构建启用离屏渲染，将原生界面写入 `/tmp/block-beautifului-smoke/`，不捕获用户桌面。真实麦克风权限和识别质量须单独验证，不能由注入文本的 smoke 证明。
