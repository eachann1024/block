# Thinkly Fast 交互与性能验收

范围：GPUI/Rust 的 Thinkly Fast。修改前基线：`3cbe3b262d0011fef24fe5fa1d4d7c4bcbd60edd`。不修改原 Thinkly 项目。

## 判定规则

- 四个模块均已完成独立排查与对抗复核，下面为去重后的实施清单。
- `☐` 表示尚未通过完整验收；实现、构建或缺陷复现成功均不能代替修复验收。部分通过写在证据列。
- 验证层级：L=纯逻辑/真实隔离文件系统；G=GPUI 模拟窗口事件和绘制；N=真实 macOS 宿主；D=设计画板检查。浏览器仅用于设计，不能验收 GPUI 应用。
- 当前项目禁止操作桌面 UI，因此 N 项保持未验证。G 可以验证事件链和布局几何，不能证明系统输入法、原生对话框和最终字体视觉正确。
- 不新增永久测试；临时检查、fixtures、基准和副本结束后删除，保留本报告的方法与实测结果。

### 长段与内存测量边界

1,600,000字节Unicode单块，同机优化级别3，3次预热/31样本，偏移0/700000/1400000均在合法UTF8边界：兼容`set_text`（包含调用者clone+字符串替换）修改前中位0.690125/0.604500/0.477583ms，修改后0.561917/0.445084/0.449125ms，均未达到旧10%。实际编辑入口`replace_range`仅替换3字节，保留旧Doc快照以触发COW时中位0.020667/0.020250/0.020292ms，p95为0.025667/0.025583/0.027209ms；不包含撤销队列、词法扫描、排版或GPUI事件。未共享快照时约0.000042ms，不能用它冒充完整输入延迟。

百万字符与10万spans的源块裁剪一个字符，定向分配探针为395bytes、5.042µs；opaque源裁剪一个字符为2bytes。十万行组合格式分别slice共27.786ms。43字节语料单文档峰值RSS：十万117,342,208bytes，百万1,117,061,120bytes（含输入与建模临时分配）；百万内存占用仍是限制。
